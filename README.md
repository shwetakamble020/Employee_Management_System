Project Description

Employee Management System is a full-stack web application used to manage employee information. Users can add, view, update, and delete employee details.

Features
Add new employees
View all employees
Update employee information
Delete employees
User-friendly interface
REST API integration
Database storage

Technologies Used
*Frontend
React.js
HTML
CSS
JavaScript

*Backend
Java
Spring Boot
Spring Data JPA
REST API

*Database
MySQL

Project Structure
EmployeeManagementSystem
│
├── frontend/       # React Frontend
│
└── backend/        # Spring Boot Backend

How to Run the Project
1. Clone the repository
git clone YOUR_REPOSITORY_URL
2. Run Backend
-Open the backend folder in Eclipse.
-Configure MySQL database.
-Update database details in application.properties.
-Run the Spring Boot application.
3. Run Frontend
Open the frontend folder in VS Code and run:
-npm install
-npm start

API Operations
1.GET – Get employee data
2.POST – Add a new employee
3.PUT – Update employee details
4.DELETE – Delete an employee
